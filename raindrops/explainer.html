Raindrops & Modulo Division

Master modulo arithmetic, conditional string construction, and basic factor checks in Go.

1. Modulo Arithmetic

The modulo operator (%) returns the remainder of integer division. It is commonly used to determine if one number is a factor of another. If a number n is divisible by d, then n % d will equal 0:

isDivisibleBy3 := (number % 3 == 0)
isDivisibleBy5 := (number % 5 == 0)

2. Separate If Statements vs Else If Blocks

In the Raindrops challenge, we need to convert numbers into sounds based on their factors: 3 ("Pling"), 5 ("Plang"), and 7 ("Plong").

Because a number can be divisible by multiple factors (for example, 15 is divisible by both 3 and 5, producing "PlingPlang"), we must check each factor using separate, independent if statements rather than a single if / else if chain:

var result string

if number % 3 == 0 {
    result += "Pling"
}
if number % 5 == 0 {
    result += "Plang"
}
if number % 7 == 0 {
    result += "Plong"
}

An if / else if block would terminate as soon as the first match is found, completely missing any subsequent matching factors.

3. Conditional String Appending

Go strings are immutable, but we can concatenate or append them using the + or += operators. If none of the factors matched (i.e. the result string is empty), we should return the original number formatted as a string. We can use strconv.Itoa() to convert an integer to a string:

import "strconv"

if result == "" {
    return strconv.Itoa(number)
}
return result

Self-Check Quiz

1. What does the expression `15 % 4` evaluate to in Go?
🎉 Correct! 15 divided by 4 is 3 with a remainder of 3. Thus, 15 % 4 = 3.
❌ Not quite. Modulo yields the remainder. 4 goes into 15 three times (12), leaving a remainder of 3.
2. Which function from the `strconv` standard package converts an integer to a string?
🎉 Correct! Itoa stands for "Integer to ASCII" (converts int to string), whereas Atoi stands for "ASCII to Integer".
❌ Oops! strconv.Atoi is for converting strings to integers (and returns an error). To convert an integer to a string, use strconv.Itoa.
3. In the Raindrops challenge, why do we use separate `if` statements instead of `else if`?
🎉 Correct! A number like 15 is divisible by 3 and 5. Separate if statements allow both to run and concatenate "Pling" and "Plang".
❌ Oops! Go fully supports else if. We avoid it here because we want multiple branches to execute if a number is divisible by more than one factor.
