Learn variables, constants, type inference, function signatures, and comments in Go.

1. Variables in Go

Go is a statically typed language. Once a variable is declared, its type is locked and cannot change. You can declare variables in two main ways:

  • Explicit Typing: Define the variable with the var keyword and specify the type explicitly: 
    var OvenTime int = 40
  • Short Variable Declaration (Implicit): Use the := operator inside a function. Go will automatically infer the type based on the value on the right: 
    ovenTime := 40 // Inferred as 'int'

2. Constants

Constants are immutable values defined with the const keyword. They are set at compile-time and cannot be changed during program execution. To assign a constant, you must use the single equals sign =, never the short declaration :=.

const OvenTime = 40 // Correct
// const PrepTime := 2  // Compiler Error!
⚠️ Mismatched Types!

If you write const OvenTime = 40.0 instead of 40, Go will infer the type as a float64 rather than an int, which can cause compiler errors when doing integer math!

3. Functions & Parameters

Go functions must specify the type of every parameter and return value explicitly. Unlike variables, parameters do not support automatic type inference:

func RemainingOvenTime(actualMinutes int) int {
    return 40 - actualMinutes
}

4. Comments

Go supports two types of comments:

  • // Single line comment
  • /* Multi-line comment block */

Self-Check Quiz

1. Which is the correct way to declare a constant in Go?
🎉 Correct! Constants are declared using the const keyword and assigned using the = operator.
❌ Incorrect. The := operator is for short variable declarations inside function bodies and cannot be used with const.
2. What happens if you define a constant as `const OvenTime = 40.0` and try to subtract it from an integer variable?
🎉 Spot on! Adding a decimal point .0 causes Go to infer a float64 type, creating mismatched types when paired with integers.
❌ Incorrect. Go does not perform implicit type conversions between integers and floats, even if the float is a whole number like 40.0.
3. Which function signature is correctly typed in Go?
🎉 Correct! Parameters must be named first, followed by their type (e.g., actual int), and the return type is placed at the end.
❌ Remember: parameter declarations in Go place the parameter name first and the type second.
