1. Numeric Types in Go

Go has several numeric types, broadly divided into integers and floating-point numbers. The most common are:

  • int: Platform-dependent size integer (either 32 or 64 bits). Used for whole numbers.
  • float64: IEEE-754 64-bit floating-point number. Used for decimals.
⚠️ No Implicit Type Conversion!

Go does not automatically convert values between different numeric types (even from int to float64). You must perform type conversion explicitly:

var speed int = 5
var rate float64 = float64(speed) * 1.2 // Explicit conversion

2. Conditionals (if / else)

Go's conditional blocks are straightforward. The condition does not require parentheses, but the statement blocks must be enclosed in curly braces { }:

if speed == 0 {
    successRate = 0.0
} else if speed <= 4 {
    successRate = 1.0
} else {
    successRate = 0.9
}
💡 Brace Placement is Strict!

In Go, the else or else if keyword must be on the same line as the closing brace } of the preceding block. Placing it on a new line causes a compilation error.

Self-Check Quiz

1. Will Go compile this expression: `var x float64 = 10 * 2.5` where 10 is an untyped constant?
🎉 Correct! Untyped constants (like literal 10 and 2.5) are evaluated at compile time and compile correctly. However, typed variables of different types would fail.
❌ Not quite. Untyped constants in expressions are highly flexible and compile fine. Explicit conversion is only required when working with typed variables.
2. Which is the correct placement for the `else` keyword in Go?
🎉 Correct! Go enforces semi-colon insertion rules, which require the else keyword to be on the same line as the preceding block's closing brace.
❌ Oops! Putting else on a new line will cause a compilation error. It must be written as } else {.
3. Which is the correct syntax for an if statement in Go?
🎉 Correct! Go does not use parentheses around conditions, but strictly requires curly braces { } even for single-line bodies.
❌ Remember: Go strictly requires curly braces { } around the block of an if statement, and no parentheses are needed around the condition.
