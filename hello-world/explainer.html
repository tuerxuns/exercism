Go Basics

Hello, Gopher!

Welcome to the Go programming language. Let's break down the basic structure of a Go source file and learn how functions work.

1. Anatomy of a Go File

Every executable Go program starts with a package declaration. Packages are Go's way of organizing and reusing code. A Go file is structured like this:

package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}

Key Components:

  • package main tells the Go compiler that this file contains the entry point of our executable program.
  • import "fmt" imports the format package from Go's standard library, which contains functions for formatting and printing text.
  • func main() is the main function where the program execution starts.

2. Defining and Returning Functions

In Go, functions are declared using the func keyword. Unlike some other languages, you declare the types of parameters and return values after their names:

func HelloWorld() string {
    return "Hello, World!"
}

In the function above, HelloWorld takes no parameters and returns a value of type string. We use the return keyword to output the string literal.

💡 Capitalization matters!

In Go, functions that start with a capital letter (like HelloWorld) are exported, meaning they can be accessed from other packages. Functions starting with a lowercase letter are private to their package.

Self-Check Quiz

1. Which package declaration must be present in Go for an executable application?
🎉 Correct! Only the main package produces an executable binary when compiled.
❌ Not quite. Go programs start executing in the main package, so package main is required.
2. How does Go determine if a function is exported (public) to other packages?
🎉 Correct! Go doesn't use public or export keywords; it uses capitalization (capital letters) to indicate public symbols.
❌ Not quite. Go does not use an "export" or "public" keyword. It relies entirely on character case (capitalization) to export functions.
3. Which of the following is the correct syntax for a function that returns a string?
🎉 Correct! In Go, the return type is declared after the parameter list.
❌ Oops! In Go, the return type (string) follows the function name and its parameter list.
