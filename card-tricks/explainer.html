Slices & Variadic Functions

A Deep Dive into Dynamic Collections and Flexible Signatures in Go

1. What is a Slice?

In Go, arrays have a fixed size that cannot be changed once declared. To provide flexible, dynamically-sized sequences of elements, Go uses Slices. A slice is a lightweight, descriptor-like wrapper built on top of an underlying array. [Go Blog: Go Slices: usage and internals]

A slice consists of three components:

  • Pointer: Points to the first element of the underlying array that is reachable through the slice.
  • Length: The number of elements currently present in the slice (retrieved with len(slice)).
  • Capacity: The maximum number of elements the slice can expand to without allocating new memory (retrieved with cap(slice)).

Defining a Slice

A slice type is written as []T, where T is the type of elements. You can initialize a slice using a literal: 

// Pre-filled slice
numbers := []int{2, 6, 9}

// Reading length and capacity
fmt.Println(len(numbers)) // Output: 3
fmt.Println(cap(numbers)) // Output: 3
⚠️ Runtime Panic: Index Out of Bounds

Accessing an index that is less than 0 or greater than or equal to len(slice) will cause a runtime panic. Always check bounds before retrieving or modifying elements by index! 

if index >= 0 && index < len(slice) {
    element := slice[index] // Safe!
}

2. Modifying & Appending

Since slices are views of an underlying array, updating an element directly modifies that array: 

cards := []int{1, 2, 4, 1}
cards[2] = 6 // Replace 4 with 6
// cards is now: [1, 2, 6, 1]

The built-in append function

To grow a slice, we use Go's built-in append(slice []T, elems ...T) []T function. [Effective Go: Slices] If the underlying array has enough capacity, append updates it in place. If not, it allocates a new array, copies the elements over, and returns a new slice pointing to the new array. 

var stack []int
stack = append(stack, 5) // Append one element
stack = append(stack, 10, 15) // Append multiple elements
// stack is now: [5, 10, 15]
💡 Try This Concept

Why do we reassign back to the slice? (e.g., slice = append(slice, val)) Because append might return a slice pointing to a completely new underlying array if the capacity was exceeded. Always store or return the return value of append!

3. Slicing Ranges & Merging

You can create a new slice from an existing one using the slice operator: slice[low:high]. This gets elements from low (inclusive) to high (exclusive). [A Tour of Go: Slices] 

fruits := []string{"apple", "banana", "cherry", "date"}

sub := fruits[1:3] // => []string{"banana", "cherry"}
all := fruits[:]   // => Copies references to the entire slice

Removing an Element

Go does not have a built-in "remove" function. Instead, we use slice expressions and append to join the segments before and after the element we want to remove: 

// Remove element at index 2 ("cherry")
fruits = append(fruits[:2], fruits[3:]...)
// fruits is now: ["apple", "banana", "date"]
🔍 The Spread Operator (...)

When merging slices or passing elements of a slice as individual arguments to a variadic function, we append ... to the slice name. This "spreads" the elements out. 

sliceA := []int{1, 2}
sliceB := []int{3, 4}
combined := append(sliceA, sliceB...) // => []int{1, 2, 3, 4}

4. Variadic Functions

A **variadic function** is a function that can accept zero or more arguments of a specific type. To declare a variadic parameter, prefix the parameter's type with an ellipsis (...). [A Tour of Go: Variadic Functions] 

// Values behaves as a slice of integers ([]int) inside the function
func PrintSum(prefix string, values ...int) {
    sum := 0
    for _, val := range values {
        sum += val
    }
    fmt.Printf("%s: %d\n", prefix, sum)
}

func main() {
    PrintSum("Result", 1, 2, 3) // Prints: Result: 6
    PrintSum("Result")          // Prints: Result: 0 (values is nil/empty)
}
💡 Rule of Thumb

The variadic parameter must be the **last** parameter in the function signature. You cannot declare other parameters after it.
