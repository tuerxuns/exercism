Slices & Slicing

Card Tricks

Master slice creation, out-of-bounds safety, and dynamic slice modifications using Go's built-in array references.

1. Slices in Go

A slice in Go is a dynamically-sized view into the elements of an underlying array. Slices are much more common than arrays due to their flexibility. Slices have 0-indexed elements:

cards := []int{5, 2, 10} // a slice containing 3 cards

You can access and modify elements directly using their index:

firstCard := cards[0] // 5
cards[2] = 8          // cards is now []int{5, 2, 8}
⚠️ Out of Bounds Panics!

Accessing an index that is negative, or greater than or equal to the length of the slice (len(cards)) will trigger a runtime panic, crashing your program. Always verify indices before accessing them!

2. Modifying Slices with append

The built-in append function adds new elements to the end of a slice, growing the slice dynamically:

cards = append(cards, 6) // adds 6 to the end

To merge or prepend another slice, use the variadic spread operator (...) to expand the slice elements:

extraCards := []int{1, 3}
// Prepend extraCards to cards:
cards = append(extraCards, cards...)

3. Slicing Slices

You can create a new slice from an existing slice using the syntax slice[low:high]. This selects elements from index low up to, but excluding, index high:

stack := []int{1, 2, 3, 4, 5}
subStack := stack[1:4] // subStack is []int{2, 3, 4} (indices 1, 2, 3)

Omit indices to default to the start or end of the slice:

  • stack[:3] yields []int{1, 2, 3} (first 3 elements).
  • stack[2:] yields []int{3, 4, 5} (from index 2 to the end).

Self-Check Quiz

1. Given `nums := []int{1, 2, 3}`, what happens if you try to evaluate `nums[3]`?
🎉 Correct! The slice length is 3 (indices 0, 1, 2). Accessing index 3 triggers a runtime index out of bounds panic.
❌ Oops! Slices are checked at runtime. Accessing index 3 (which equals the length of the slice) will crash the program with a runtime panic.
2. How do you prepend a slice `stack` to a slice `extra` (putting `extra` elements at the front of `stack`)?
🎉 Correct! append(extra, stack...) creates a new slice by taking the elements of extra and unpacking the elements of stack after them.
❌ Not quite. You must use the spread operator (...) to expand the stack slice. Appending extra... to stack would put extra at the back, not the front.
3. What does `stack[1:3]` return for `stack := []int{10, 20, 30, 40}`?
🎉 Correct! The range [1:3] takes elements from index 1 (20) up to, but excluding, index 3 (40), yielding []int{20, 30}.
❌ Oops! Slicing is half-open: it includes the element at the low index (1) but excludes the element at the high index (3).
