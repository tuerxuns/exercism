Collatz Conjecture

Exploring the classic mathematical sequence, Go's simplified loops, and safe error handling.

1. The Collatz Conjecture Rules

The Collatz Conjecture is a famous mathematical puzzle. It says that if you start with any positive integer n and repeatedly apply the following rules, you will eventually reach the number 1:

  • If the number is even: divide it by 2 (n / 2).
  • If the number is odd: multiply it by 3 and add 1 (3 * n + 1).

In Go, we can check if a number is even or odd using the modulo operator (%): 

if n % 2 == 0 {
    // n is even
} else {
    // n is odd
}
💡 Did You Know?

No one has ever mathematically proven that every positive integer reaches 1, although computers have checked numbers up to 268! It's one of the most famous unsolved problems in mathematics.

2. Go's "While" Loop

To count the steps to reach 1, we must repeatedly apply our rules as long as the current number is greater than 1. This is a classic "conditional loop" (often called a while loop).

While many languages have a dedicated while keyword, Go keeps things minimalist. Go only has one loop construct: the for loop.

To write a "while-style" loop in Go, we simply omit the initialization and post statements, leaving only the condition: 

// This loop runs as long as n is greater than 1
for n > 1 {
    if n % 2 == 0 {
        n = n / 2
    } else {
        n = 3 * n + 1
    }
    // Increment steps counter here...
}

This structure is elegant and clean. Once the condition n > 1 becomes false (i.e., when n reaches 1), the loop exits automatically.

3. Introducing Error Handling

The Collatz Conjecture is only defined for positive integers (n ≥ 1). If the input is 0 or negative, the process is invalid. In Go, functions represent failure by returning an error type as their final return value.

In the function signature: 

func CollatzConjecture(n int) (int, error)
The function returns two values:
  1. An int representing the step count.
  2. An error representing whether an error occurred.

How to Return Errors

We can create a simple error using Go's built-in errors package: 

import "errors"

// In your function:
if n <= 0 {
    return 0, errors.New("input must be a positive integer")
}

If the calculation succeeds and no error occurs, we return the step count alongside nil (which represents the absence of an error): 

return steps, nil
