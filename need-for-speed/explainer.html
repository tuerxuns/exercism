Go Structs & Pointers

Structs, Pointers & Methods

Organize related data using structs, manage memory efficiently with pointers, and attach behavior using methods.

1. Structs in Go

A struct is a typed collection of fields. It is used to group data together to form a custom data type. For example, to represent a car:

type Car struct {
    battery      int
    batteryDrain int
    speed        int
    distance     int
}

You can construct a struct instance using a struct literal:

myCar := Car{
    battery:      100,
    batteryDrain: 5,
    speed:        10,
}

2. Pointers in Go

A pointer stores the memory address of a value. Pointers allow you to pass references to values instead of copying them:

  • The address-of operator (&) generates a pointer to a variable.
  • The dereference operator (*) accesses the value at a pointer's memory address.
var car Car = Car{battery: 100}
var carPointer *Car = &car // carPointer holds the address of car
(*carPointer).battery = 90 // updates car.battery
💡 Go's Syntactic Sugar!

In Go, you don't need to write (*carPointer).battery. You can write carPointer.battery directly; Go automatically handles dereferencing for struct pointers.

3. Methods and Receivers

Go doesn't have classes, but you can define methods on struct types. A method is a function with a special receiver argument:

// Value Receiver: receives a copy of the struct
func (c Car) DisplayDistance() string {
    return fmt.Sprintf("Driven %d meters", c.distance)
}

// Pointer Receiver: receives a pointer, allowing modifications to the struct
func (c *Car) Drive() {
    c.distance += c.speed
    c.battery -= c.batteryDrain
}
⚠️ When to use Pointer Receivers?

Use a pointer receiver if: (1) you need to modify the receiver's fields, or (2) the struct is large and copying it on every method call would be slow.

Self-Check Quiz

1. Which operator is used to get the memory address of a variable in Go?
🎉 Correct! The address-of operator (&) returns the pointer/address of a variable.
❌ Not quite. & generates a pointer to a value, whereas * dereferences a pointer.
2. Why would you define a method with a pointer receiver `(c *Car)` instead of a value receiver `(c Car)`?
🎉 Correct! A pointer receiver allows the method to mutate the struct fields. Value receivers only receive a copy.
❌ Not quite. Value receivers work on copies and cannot modify the original struct's state. You must use pointer receivers for mutations.
3. What is the value of a struct pointer that is declared but not initialized?
🎉 Correct! The zero value of a pointer is nil.
❌ Oops! Since pointers store memory addresses, a pointer declared without an address is nil.
