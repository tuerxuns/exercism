Go Control Flow

Switch Statements

Replacing long if/else chains with elegant, readable, and highly powerful switch blocks.

1. The Basic Switch

A switch statement checks a value against multiple options (declared with case keywords) and runs the code block of the first match. You can provide a default case that executes if none of the cases match: 

card := "queen"

switch card {
case "ace":
    value := 11
    fmt.Println(value)
case "king":
    value := 10
    fmt.Println(value)
default:
    fmt.Println("Unknown card")
}
⚠️ No Automatic Fallthrough!

Unlike C, Java, JavaScript, or C++, Go does not fall through to the next case automatically. Once a case is matched and finished executing, the switch statement terminates. No manual break statement is needed!

2. Handling Multiple Values

If several cases share the same output or behavior, you don't need to write them separately. You can list multiple values in a single case statement by separating them with commas: 

card := "queen"
var value int

switch card {
case "jack", "queen", "king", "ten":
    value = 10
case "two":
    value = 2
default:
    value = 0
}
fmt.Println(value) // Output: 10

3. The Conditionless Switch

In Go, you can omit the value expression after the switch keyword. When you do this, each case behaves like an if condition that must evaluate to a boolean (true or false). The switch executes the first case that evaluates to true: 

score := 18
dealerScore := 8

switch {
case score > 21:
    fmt.Println("Bust!")
case score > dealerScore:
    fmt.Println("Win!")
default:
    fmt.Println("Stand.")
}

Self-Check Quiz

1. Does Go require a `break` statement at the end of each case block to prevent falling through?
🎉 Correct! Go automatically exits the switch block once a matching case runs. Fallthrough does NOT happen unless the explicit fallthrough keyword is used.
❌ Not quite. Go does not require break. It automatically breaks out of the switch block unless you explicitly write fallthrough.
2. How do you check if a card variable is equal to "jack", "queen", or "king" in a single case statement?
🎉 Correct! In Go, we group multiple values for a single case by separating them with commas.
❌ Not quite. You cannot use logical operators like || in a switch expression case value. Use commas instead.
3. What is the behavior of a conditionless switch block (`switch { ... }`)?
🎉 Correct! A conditionless switch behaves exactly like a cleaner chain of if / else if conditions.
❌ Not quite. Go fully supports conditionless switches. Each case evaluates its own boolean expression.
