1. Go Strings

In Go, a string is an immutable sequence of bytes. Once a string is created, its value cannot be changed. Any operation that appears to modify a string actually creates a brand-new string in memory.

You can declare string literals using double quotes (with escape sequences) or backticks (raw strings):

escapedStr := "Hello\nWorld" // contains newlines
rawStr := `Line 1
Line 2` // keeps original layout exactly

2. The strings Package

Go provides the strings package in its standard library to perform common text manipulation tasks efficiently:

  • strings.HasPrefix(s, prefix): Checks if string s starts with prefix. 
    isWelcome := strings.HasPrefix("Welcome Guest", "Welcome") // true
  • strings.ToUpper(s): Returns a copy of s converted to uppercase.
  • strings.ReplaceAll(s, old, new): Replaces all occurrences of old with new.
  • strings.TrimSpace(s): Removes leading and trailing whitespace characters (spaces, tabs, newlines). 
    cleaned := strings.TrimSpace("   Hello Gopher! \n") // "Hello Gopher!"

Self-Check Quiz

1. Are Go strings mutable (can be changed element-by-element after creation)?
🎉 Correct! Strings are immutable. Reassigning or concatenating strings creates new strings in memory.
❌ Not quite. Go strings are immutable. You cannot modify individual characters directly.
2. Which function from the `strings` package removes leading and trailing spaces?
🎉 Correct! strings.TrimSpace strips out tabs, spaces, and newline sequences from both ends.
❌ Oops! The correct standard library function name is strings.TrimSpace.
3. What is the difference between raw string literals (with backticks) and standard string literals (with quotes)?
🎉 Correct! Raw strings defined with backticks ` preserve format, spaces, and do not process escape characters.
❌ Oops! Raw string literals ignore backslashes and can stretch across multiple lines directly, preserving all layout details.
