# Mission: Learning Programming with Go

## Why
Learn programming by solving Go exercises, building a solid foundation in software development concepts (data types, loops, functions, memory, structs) so that you can think like a developer and write software independently.

## Success looks like
- Successfully solving Go exercises on Exercism.
- Explaining core coding concepts (variables, types, conditionals, loops, functions, structs, pointers) in your own words.
- Reading and understanding error messages, compilation errors, and unit test outputs to debug your own code.
- Writing clean, compiling, and idiomatic Go code that passes test suites.

## Constraints
- **Prior Experience:** Already completed introductory exercises (Hello World, Lasagna, Cars Assemble, Raindrops, etc.). Has basic familiarity with variables, types, conditionals, and functions.
- **Learning Mode active:** No copy-paste code solutions. Always teach and guide via conceptual explanations, small steps, and hints.
- **Hands-on practice:** You write all the code yourself.
- **Git Sync Rule:** When committing and pushing progress, stage and commit *everything* (all files/folders in the workspace) unless they are explicitly ignored in `.gitignore`.

## Out of scope
- Advanced Go topics (concurrency/goroutines, channels, reflection, context) until the basics are fully mastered.
- Complex database connections, server deployments, or Docker configurations.
