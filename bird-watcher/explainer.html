For Loops in Go

Mastering the only looping construct in Go

1. The Standard Three-Component Loop

Unlike many other languages that feature while, do-while, and for loops, Go has **only one** looping construct: the for loop. [A Tour of Go: For]

The standard three-component loop is structured as follows: 

for init; condition; post {
    // Loop body
}
  • init: Runs once before the loop begins. Typically used to declare a counter variable (e.g. i := 0).
  • condition: Evaluated before every iteration. If it is true, the loop runs; if false, the loop ends.
  • post: Runs at the end of every iteration. Typically increments the counter (e.g. i++).
⚠️ No Parentheses allowed

In Go, you **do not** place parentheses ( ) around the header components. Doing so will result in a compilation error! The curly braces { } are always required.

2. Iterating Over Slices by Index

A very common use of for loops is to traverse through elements of a slice using index access. The loop counter starts at 0 and increments up to, but not including, the length of the slice (len(slice)). 

birds := []int{2, 5, 0, 7}

for i := 0; i < len(birds); i++ {
    fmt.Printf("Day %d: counted %d birds\n", i, birds[i])
}

Slicing a Range Before Looping

If you only want to loop through a subset of a slice (e.g. a specific week's worth of data), you can take a slice of the slice first: 

// Get only the second week (indices 7 to 13)
weekTwo := birdsPerDay[7:14]

for i := 0; i < len(weekTwo); i++ {
    // Process weekTwo[i]
}

3. Custom Steps (Alternate Increments)

The post component can be modified to step through the collection differently. Instead of adding 1 (i++), you can add any step size, such as 2 (i += 2).

This allows you to visit every second element, starting from index 0: 

numbers := []int{10, 20, 30, 40, 50, 60}

for i := 0; i < len(numbers); i += 2 {
    // i will be 0, 2, 4
    fmt.Println(numbers[i]) // Output: 10, 30, 50
}
💡 Remember: While loops in Go

Since Go has no while keyword, you can create a while-loop by omitting the init and post statements: 

sum := 1
for sum < 1000 {
    sum += sum
}
