Go Loops

For Loops in Go

Master loop syntax, iterating over slices with range, custom steps, and modern Go 1.22+ range-over-integer patterns.

1. The Standard Three-Component Loop

Unlike many other languages that feature while, do-while, and for loops, Go has only one looping construct: the for loop.

The standard three-component loop is structured as follows: 

for init; condition; post {
    // Loop body
}
  • init: Runs once before the loop begins. Typically used to declare a counter variable (e.g. i := 0).
  • condition: Evaluated before every iteration. If it is true, the loop runs; if false, the loop ends.
  • post: Runs at the end of every iteration. Typically increments the counter (e.g. i++).
⚠️ No Parentheses allowed

In Go, you do not place parentheses ( ) around the header components. Doing so will result in a compilation error! The curly braces { } are always required.

2. Iterating Over Slices with range

The most idiomatic way to loop over a slice in Go is using range. It gives you both the index and the value at each step: 

birds := []int{2, 5, 0, 7}

for i, count := range birds {
    fmt.Printf("Day %d: counted %d birds\n", i, count)
}

If you only need the value and not the index, discard the index using the blank identifier _: 

for _, count := range birds {
    // use count directly — no index needed
    total += count
}

Range Over Integer (Go 1.22+)

Since Go 1.22, you can also range directly over an integer. This is a clean modern alternative to the classic three-component loop when you just need a counter: 

// Prints 0, 1, 2, 3, 4
for i := range 5 {
    fmt.Println(i)
}
💡 Which style should I use?

Use for _, v := range slice when you want values from a slice. Use for i := range n when you just need a counter. Use the classic three-component loop when you need fine-grained control over the step size (e.g. i += 2).

3. Custom Steps & While-Style Loops

When you need to visit every second element (e.g. fix alternate day counts), the three-component loop lets you control the step size precisely: 

numbers := []int{10, 20, 30, 40, 50, 60}

for i := 0; i < len(numbers); i += 2 {
    // i visits: 0, 2, 4
    numbers[i]++ // increment every alternate element
}

range always steps by 1, so the classic loop is the right choice when you need a different step size.

💡 While-style loops in Go

Since Go has no while keyword, omit the init and post to get a while-style loop: 

sum := 1
for sum < 1000 {
    sum += sum
}

Self-Check Quiz

1. Which of the following is a valid Go loop declaration?
🎉 Correct! Go does not use parentheses in loop headers, and while is not a keyword in Go.
❌ Incorrect. Go has no while keyword and does not allow parentheses around loop headers.
2. What does for _, v := range birds give you on each iteration?
🎉 Correct! The blank identifier _ discards the index, leaving you with just the value v on each iteration.
❌ Not quite. range produces both an index and a value. Using _ throws away the index so you only work with the value.
3. In Go 1.22+, what does for i := range 5 produce?
🎉 Correct! Since Go 1.22, ranging over an integer n produces values from 0 up to, but not including, n — just like a classic for i := 0; i < n; i++.
❌ Not quite. Go 1.22 introduced range-over-integer. It starts at 0 and counts up to (but not including) the given number — so range 5 gives 0, 1, 2, 3, 4.
