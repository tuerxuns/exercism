# Go Programming Resources

## Knowledge

### Official Documentation
- [Official Guide: Go documentation](https://go.dev/doc/)
  The root of all official Go learning materials, tutorials, and standard library packages.
- [Official Documentation: Effective Go](https://go.dev/doc/effective_go)
  Guidelines for writing clear, idiomatic Go code. Use for: learning best practices once the basics are understood.
- [Official Documentation: Go Doc Comments](https://go.dev/doc/comment)
  Rules and conventions for writing documentation comments in Go code. Use for: understanding package and function documentation standards.

### Interactive Tutorials & Websites
- [Official Website: A Tour of Go](https://go.dev/tour/)
  Interactive introduction to Go syntax, data structures, and methods. Use for: quick syntax checks and basic type experiments.
- [Official Website: A Tour of Go - For Loops](https://go.dev/tour/flowcontrol/1)
  Interactive introduction to Go's for loop statement, including the init, condition, and post components. Use for: understanding basic loop structures.
- [Official Website: A Tour of Go - For is Go's "while"](https://go.dev/tour/flowcontrol/2)
  How to write while-style loops in Go by omitting init and post. Use for: simplified loops.
- [Official Website: A Tour of Go - Structs](https://go.dev/tour/moretypes/2)
  Interactive introduction to declaring and using Go structs. Use for: learning basic struct modeling.

### Standard Library Packages
- [Standard Library: strings package](https://pkg.go.dev/strings)
  Official documentation and example code for the standard string manipulation package. Use for: looking up string replacement, trimming, and casing methods.

### Deep-Dives & Blogs
- [Official blog: Go Slices: usage and internals](https://go.dev/blog/slices-intro)
  Deep dive into slice data structures, length/capacity headers, and how append works. Use for: understanding slice memory management.


## Wisdom (Communities)

- [Exercism Go Track](https://exercism.org/tracks/go)
  Platform for practice, mentoring, and code reviews from real human mentors.
- [r/golang](https://reddit.com/r/golang)
  Subreddit dedicated to the Go programming language. Use for: asking community questions, staying updated on Go ecosystem.
