Understand comparison operators, string ordering, and if/else decision paths in Go.

1. Comparison Operators

Go provides standard comparison operators that evaluate to boolean values (true or false):

  • == (equal to) and != (not equal to)
  • < (less than) and > (greater than)
  • <= (less than or equal to) and >= (greater than or equal to)

Go is strictly typed; you can only compare variables that share the exact same type. Comparing an int to a float64 directly will cause a compile-time error.

2. Comparing Strings Alphabetically

In Go, strings can be compared using comparison operators (<, <=, >, >=). The comparison is done lexicographically (alphabetically based on Unicode code points):

isFirst := "Apple" < "Banana" // true
isSecond := "Tesla" < "Toyota" // true
💡 Case sensitivity!

Capital letters have smaller Unicode values than lowercase letters. Therefore, "Zebra" < "apple" is true! To perform case-insensitive comparisons, use the strings.ToLower function or strings.EqualFold.

3. Multi-branch Conditionals

For more complex decisions, use else if and else branches. Keep in mind that conditions must evaluate to a boolean value, and Go doesn't have "truthy" or "falsy" values:

if age < 3 {
    price = originalPrice * 0.8 // 80% of original price
} else if age >= 10 {
    price = originalPrice * 0.5 // 50% of original price
} else {
    price = originalPrice * 0.7 // 70% of original price
}

Self-Check Quiz

1. What does the expression `"Ford" < "Fiat"` evaluate to in Go?
🎉 Correct! Alphabetically, "Fiat" comes before "Ford" (since "i" comes before "o"), making "Fiat" smaller than "Ford". Thus, "Ford" < "Fiat" is false.
❌ Not quite. Alphabetically, "i" in "Fiat" comes before "o" in "Ford". So "Fiat" is smaller, and "Ford" < "Fiat" is false.
2. Can you compare an int variable `age` to a float64 literal `3.0` directly using `age < 3.0`?
🎉 Correct! Go does not support mixed-type comparison between typed variables and typed expressions. You must explicitly cast the variables.
❌ Oops! Go's compiler is strict. It does not allow direct comparison of different types (int vs float64) without explicit casting.
3. In Go, what is the boolean value of an uninitialized bool variable?
🎉 Correct! The zero value of a bool type in Go is false.
❌ Oops! All variables in Go are initialized to their zero value. For booleans, the zero value is false.
