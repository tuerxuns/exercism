# Starting Bird Watcher in Go

The student is beginning the `bird-watcher` exercise to learn about loops, specifically the `for` loop, slice iteration, index ranges, and stepping logic.

## Goals
- Learn the syntax of the standard three-part `for` loop in Go (`for init; condition; post`).
- Practice iterating over a slice using indices.
- Apply step manipulation (iterating by 2s) and slicing ranges.

## Starting Plan
- Step 1: Explain the standard `for` loop syntax.
- Step 2: Guide the student through implementing `TotalBirdCount` (summing a slice).
- Step 3: Guide the student through implementing `BirdsInWeek` (summing a range of a slice).
- Step 4: Guide the student through implementing `FixBirdCountLog` (manipulating values on alternate days).
