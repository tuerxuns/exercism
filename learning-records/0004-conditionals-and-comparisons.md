# Mastering Conditionals and Comparisons

The student successfully solved the `vehicle-purchase` exercise, demonstrating strong competence in logical operations, conditional paths, and lexicographical string comparisons. We also discussed how boolean conditions can be returned directly instead of wrapped in an `if-return-bool` block, and how control flow can be simplified by removing redundant checks.

## Evidence

- Used `||` (logical OR) to check vehicle types in `NeedsLicense`.
- Used `<` for string comparison in `ChooseVehicle` to determine alphabetical precedence.
- Implemented multiple `if` branches in `CalculateResellPrice` using conditions like `age < 3`, `age < 10.0 && age >= 3`, and a default fallback.

## Implications

- Solid grasp of multi-branch conditionals and string comparison in Go.
- Ready for switch statements as a more structured alternative to long if/else chains.
